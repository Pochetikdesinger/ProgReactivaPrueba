# Sistema de Gestión de Inventario

Este proyecto es un sistema de gestión de inventario desarrollado con Spring Boot, MongoDB y WebSocket. Permite gestionar productos mediante una API REST reactiva y enviar notificaciones en tiempo real a través de WebSocket.

## Tecnologías utilizadas
- **Backend**: Spring Boot (programación reactiva con Flux y Mono)
- **Base de datos**: MongoDB
- **API REST**: Endpoints para crear (`POST`) y listar (`GET`) productos
- **WebSocket**: Notificaciones en tiempo real para actualizaciones de inventario
